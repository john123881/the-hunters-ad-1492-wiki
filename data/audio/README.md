# 《獵人：西元1492》語音檔案分類說明 (Audio Archive Documentation)

本目錄存放由劇本伴侶網頁（`music=base` / Webpack Module `Hx70`）所下載之《獵人：西元1492》（The Hunters A.D. 1492）全量中文劇情旁白語音檔案（共 722 首）。

對照表資料請參閱根目錄下的 [`data/audio_map.json`](file:///home/john/projects/the-hunters-ad-1492/data/audio_map.json)。

---

## 📂 子目錄結構與定義說明

| 子資料夾名稱 | 代號前綴規則 | 分類定義 | 收錄數量 | 說明與範例代號 |
| :--- | :--- | :--- | :---: | :--- |
| `quest/` | `Q` 開頭 | **任務** | 23 首 | 主線戰役任務卡引言旁白。<br>範例：`Q1`, `Q2`, `Q20`, `Q52` |
| `quest_win/` | `V` 開頭 | **任務勝利** | 50 首 | 任務結算「勝利」時的劇情尾聲（含分支卡）。<br>範例：`V1`, `V27A`, `V27B`, `V32A1`, `V49` |
| `quest_loss/` | `L` 開頭 | **任務失敗** | 46 首 | 任務結算「失敗」時的劇情尾聲（含分支卡）。<br>範例：`L1`, `L17`, `L27A`, `L41A`, `L49` |
| `character/` | `F` 開頭 | **角色卡** | 17 首 | 獵人角色背景故事與專屬旁白。<br>範例：`F001` ~ `F016`, `F101` |
| `w_quest/` | `W` 開頭 | **W擴充任務** | 1 首 | 擴充戰役任務前言語音。<br>範例：`W2` |
| `w_quest_win/` | `VW` 開頭 | **VW擴充任務勝利** | 8 首 | 擴充任務結算「勝利」時的語音。<br>範例：`VW1` ~ `VW8` |
| `w_quest_loss/` | `LW` 開頭 | **LW擴充任務失敗** | 7 首 | 擴充任務結算「失敗」時的語音。<br>範例：`LW1` ~ `LW7` |
| `story/` | 純數字或帶字母後綴 | **劇情卡** | 570 首 | 故事書章節、遭遇事件、特殊抉擇與導讀。<br>範例：`1`（5分22秒開場導讀）, `101`, `201`, `3704`, `8001` |

## 🛠️ 維護與重新下載說明

若需要重新校對或下載語音檔案，可透過以下腳本操作：

1. **重新建立乾淨對照表**：
   ```bash
   node scripts/build-categorized-audio-map.mjs
   ```
2. **批次下載與斷點續傳**：
   ```bash
   node scripts/download-audio.mjs
   ```
   * 腳本內建 HTTP Range 續傳、暫存 `.part` 保護以及失敗自動重試機制。
   * 下載的音訊檔案（`.mp3`）預設被 `.gitignore` 排除，不納入 Git 版本庫以避免儲存庫膨脹。
